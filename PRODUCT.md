# Product

## Register

product

## Users

Moonshot Frisbee Games players entering a browser-based campus frisbee game. They need the resource gate to show clear loading progress and a deliberate entry action before they reach the existing home screen.

## Product Purpose

Provide a fast, understandable path from page load to the game homepage and then into the FF-01 campus. Loading feedback must be truthful, and the entry action must preserve browser audio activation.

## Brand Personality

Competitive, bright, trustworthy. Keep the existing Moonshot esports identity and make the loading state feel like part of the game rather than a generic software dashboard.

## Anti-references

- Generic SaaS dashboard loading screens.
- Replacing or redesigning the existing homepage when changing the boot screen.
- Progress that implies completion before assets are ready.

## Design Principles

- Show the game identity while resources prepare.
- Make loading progress and the next action immediately legible.
- Preserve the existing home screen and campus-entry flow.
- Use motion to communicate progress, with a reduced-motion alternative.

## Accessibility & Inclusion

Keep loading status available to assistive technology, provide keyboard-visible focus on the continue action, and respect `prefers-reduced-motion`.
