# Skill pickup model sources

These OpenGameArt archives are retained as the immutable inputs for the runtime GLBs in `public/assets/pickups/`.
The generated manifest records the archive hashes, model hashes, dimensions, authors, and source pages.

| In-game use | Source | Author | License |
| --- | --- | --- | --- |
| Revive armor medkit | [First Aid Kit 3D](https://opengameart.org/content/first-aid-kit-3d) | GGBotNet | CC0 |
| Monitoring eye | [Low-poly Monitor](https://opengameart.org/content/low-poly-monitor) | Mitylernal | CC0 |
| Stealth crystal | [LowPoly Crystals](https://opengameart.org/content/lowpoly-crystals) | Aredon | CC0 |
| Creation gear | [Gear Pack](https://opengameart.org/content/gear-pack) | Elegant Crow | CC BY-SA 4.0 |

The gear runtime GLB is derived from `gear_12.obj` and its 512 px texture. It was converted to GLB and uniformly resized to 0.70 m high. Its attribution and share-alike terms are included beside the published runtime asset.

FRC uses the game's own frisbee-shaped runtime mesh, colored red with authored emissive rings and accents; it does not use an external model.
