# FF-01 runtime asset pipeline

## Source and derivative

The source archive `MAC_Campus_FF01_3D_Export.zip` was supplied locally and is not stored in this repository. The runtime model is the archive's unmodified `models/MAC_Campus_FF01.glb`, SHA-256 `2580173bb23c56961c033f4eafeb01dfd4eec047d5ebd2bee8fc9bf16c9a57a4`. Its root scale and authored coordinate system are preserved. It is explicitly `SOURCE_DERIVED_3D_UNVERIFIED`; dimensions and room boundaries are not field-surveyed.

`rooms.json` is a curated runtime derivative of the archive's `data/rooms.json`. It preserves model/frame metadata, all 165 room IDs and names, geometry status, and the 159 source polygons (including holes). It omits descriptions, access, capacity, sensor bindings, source PDFs, website configuration, and all other archive content. The six label-only spaces retain no invented polygons.

The hashes and counts are in `public/assets/campus/manifest.json`; `npm test` verifies the GLB header, source identity, structural node names, hash integrity, room counts, polygon shape, and omitted data fields. The original ZIP is never copied into Vite's public tree.

## Distribution boundary

The runtime assets are publicly served at <https://moonshot-csgo.pages.dev/>. On 2026-10-15, the repository owner explicitly approved public hosting of the FF-01 GLB and curated room derivative after reviewing that they expose the campus-derived first-floor layout and room names. The source ZIP, source plans, sensor endpoint, and demo content remain excluded. The deployment does not enable Cloudflare Access; the site and runtime assets are available to anyone with the URL.

## Import behavior

PlayCanvas loads the GLB as a `container`, instantiates its render hierarchy without a transform adapter, and requires the model identity and structural node set expected by the manifest. Room color patches, floor linework, and label anchors are hidden in the runtime scene. Collision is added separately in M0.2 and is not inferred from every visible mesh.

## Derived presentation data (`public/assets/campus/derived/`)

Generated by `npm run derive:world` (`tools/deriveWorld.ts`) from the unmodified GLB and curated `rooms.json`; `manifest.json` records the source hashes and output hashes, and `npm test` re-derives everything in memory and requires an exact match. All of it is `GAMEPLAY_AUTHORED` interpretation, not survey data.

| Output | Derivation |
| --- | --- |
| `world.json` → arena | Flood fill from the court centre between walls and room polygons, clipped to a 26 m radius (the north/south corridors open into the ring corridor), opened/closed morphologically and traced to a simplified outline. Treated as open-air; the runtime raises a 10 m perimeter wall along it. |
| `world.json` → doors | Quarter-circle swings in `Lines_Doors`; the hinge is the arc centre and the closed tip is the end whose extension runs into a wall. Lintels span hinge→closed tip from 2.15 m to the wall top; leaves are drawn open. Door gaps without a drawn swing get no door. |
| `world.json` → furniture | Small regions enclosed by `Lines_Furniture` (0.04–4.5 m², boxy, away from doors) become boxes: <0.2 m² seats 0.45 m, long/narrow counters 0.9 m, others tables 0.75 m. Restroom linework becomes 1.8 m partitions. Most classrooms have no furniture linework and stay empty. |
| `world.json` → doorways | One doorway per room the source walls seal off, at the thinnest single-wall crossing into reachable floor (see [COLLISION_AUDIT.md](COLLISION_AUDIT.md)). Cut at load; the source GLB is unchanged. |
| `world.json` → layout furniture | For rooms with fewer than three linework items, a per-kind layout in the room's oriented frame: classrooms (teacher's desk at the front, paired desks with chairs facing it), labs (benches with stools), libraries (shelves), offices (desk and chair), meeting rooms (one table with chairs), dining (tables for four), creative rooms (tables with stools), courtyards (benches). Each item must lie inside the room, ≥ 0.35 m from walls, ≥ 1.1 m from doors and clear of other items. `source: "layout"` marks them as authored. |
| Authored rooms | Rooms listed in `src/world/rooms/index.ts` (`AUTHORED_ROOM_IDS`, currently M104) get no linework/layout furniture and no generic lights; the runtime builds their photo-referenced interior instead. |
| `world.json` → lights | Ceiling fixture positions on a 3.2 m grid inside room polygons and a 4.5 m grid in corridors, clear of walls. |
| `ceiling-mask.png` | 0.1 m/px, row 0 at Z = −62: white where the ceiling is drawn, black over the arena and the two courtyards. |
| `minimap.png` | 0.2 m/px floor map: walls, glazing, rooms by kind, courtyards, arena, court and stands. |
