## 启动与使用

```sh
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

打开 <http://127.0.0.1:5174/?audioLab=1&offline=1>。此模式强制离线，只有开发构建启用试音靶和面板，不连接生产房间、不写战绩。

1. 按 P，或点击右上角“音效配置 · P”。输入框、下拉框编辑期间不会截获字母 P。
2. 当前优先使用“金飞盘击杀 / 飞盘破空”两栏，候选按来源和用途分组。选择金盘片段会自动开启人偶金盘试音；破空声在实际普通/狙击投掷时触发。其余四栏保留生产默认音效，选择“原有音效”可取消覆盖。
3. 可以调音量、起点和终点，点击试听；勾选循环可反复比较。测试覆盖所选事件的确认声，原有提示不会与候选重复叠加。
4. 人偶固定在南入口出生点正前方 4 m：`[-8.7, 0.92, 42.3]`，为 GAMEPLAY_AUTHORED 测试实体。可以直接从出生点投掷；“去试音靶场并进入游戏”会将玩家带回出生点并朝向人偶。人偶无动力刚体，不会被击退或追随玩家。
5. 人偶 2 点生命；身体两次命中淘汰，满血爆头直接淘汰。死亡后隐藏并停止接收命中，2.5 s 后在完全相同的位置满血复活。右上角显示生命与复活倒计时，不记录真实战绩。
6. P 暂停并打开/关闭配置（原 F8 兼容保留）；也可以先按 Esc，再点右上角按钮。点击“继续游戏”重新锁定鼠标。

素材清单缺失会给出错误；选择异步加载使用版本检查，快速切换不会被旧请求覆盖。每个事件至多保留一个测试声部，关闭面板会停止试听。片段选择仅在本页会话生效，刷新恢复原声。
