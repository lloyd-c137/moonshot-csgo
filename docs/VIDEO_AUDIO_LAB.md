# 视频音效拆分与本地游戏试音

用户于 2026-10-16 提供 `740588fdd5a6ae2ca2315cca86339e56.mp4`，并要求在游戏内自由切换拆出的音效。

## 拆分结果

- 原视频音轨：AAC、44.1 kHz、单声道，48.342494 s（视频画面约 48.367 s）。
- 使用 macOS `afconvert` 解码；按 10 ms RMS 大于 −38 dBFS 的声音事件划分，合并小于等于 140 ms 的间隙，前留 18 ms、后留 75 ms；忽略不足 220 ms 的孤立事件，片段边界各加 3 ms 淡变。
- 共 27 个 WAV 片段（26 个短事件、1 个约 6.27 s 的连续混合片段），总计 2,533,482 字节。命名 `v01.wav` 到 `v27.wav`，清单包含每段原视频起止时间、时长、SHA-256 和电平。
- 这是按事件边界切片，不是声源分离：没有声称已去除背景音乐、说话或重叠声；连续混合段明确标记，用户还可在测试面板里继续调整起止点。也没有凭画面把所有片段认定为某种特定命中声。
- 完整本地清单：`.audio-lab-local/manifest.json`；片段：`.audio-lab-local/clips/`。原始视频与完整解码音轨保存在用户 Downloads 的 `moonshot-video-audio-staging/`。
- 另输出了 `/Users/mac/Downloads/moonshot_video_split_27_clips.zip`，包含全部片段和清单。

视频标注 CSGO，没有可确认的再发布许可；源视频与衍生音频仅作本地评估，目录被 Git 忽略，未放在 public/，生产构建不会包含这些文件。

## 启动与使用

```sh
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

打开 <http://127.0.0.1:5174/?audioLab=1&offline=1>。此模式强制离线，只有开发构建启用试音靶和面板，不连接生产房间、不写战绩。

1. 点击右上角“音效测试 · F8”。
2. 在“身体命中 / 爆头确认 / 飞盘碰撞”三个下拉框里独立选择 27 个片段中的任意一段。选择“原有音效”恢复原声。
3. 可以调音量、起点和终点，点击试听；勾选循环可反复比较。测试覆盖所选事件的确认声，原有提示不会与候选重复叠加。
4. 点击“去试音靶场并进入游戏”，前方 6 m 是现有 M104 走廊中的 GAMEPLAY_AUTHORED 试音靶。对头部/身体投掷，向地面或墙面投掷测试碰撞。靶可重复命中。
5. F8 暂停并重新切换（Mac 媒体键模式可能需要 Fn+F8）；也可以先按 Esc，再点右上角按钮。点击“继续游戏”重新锁定鼠标。

素材清单缺失会给出错误；选择异步加载使用版本检查，快速切换不会被旧请求覆盖。每个事件至多保留一个测试声部，关闭面板会停止试听。片段选择仅在本页会话生效，刷新恢复原声。
