## 不优先采用的系列

- Soft：测得能量几乎全在 400 Hz 以下；可作受伤低频补层，不建议单独作为命中确认。小音箱是否清楚需要实听。
- Bell、Plate、Tin、Mining、Metal：不作为身体命中的通用默认声；文件分类和频谱/时长更适合另行评估材质或特殊提示。没有试听，不把其名称当作真实录音材质保证。
- Glass medium/heavy：不优先用于不可破坏玻璃；需要先排除碎裂暗示。轻玻璃目前也仅是条件候选。
- Punch heavy：只留 002，它是该组最短的文件（约 457 ms），95% 能量在约 101 ms 内；不用于每一次普通弹跳。
- 脚步 Carpet/Concrete/Grass/Snow/Wood：本次不选；当前任务是战斗碰撞音效。
- 该包没有明确的 whoosh / fly-by / 专用 kill-confirm 分类。投掷破风、掠过和击杀确认仍需保留现有合成/用户音频或另找素材。

## 后续接入时的边界

1. 身体命中分开处理“物理接触声”与“确认提示声”：Punch 是前者，现有高频提示继续承担后者。
2. 普通/狙击/金盘淘汰应共享基础淘汰确认，再叠差异层；保留用户指定 kill.mp3 / defeat.mp3。
3. 当前 bounce(at, strength) 没有材质参数；Wood/Glass 接入需要从碰撞实体传递材质，不应随机播放成玻璃。
4. 下一步可以给候选制作单声道、裁剪无效尾部和短淡出的运行版本，但需重新测量并实听；本次候选原文件未转码或归一化。
5. 保持单声部短提示，限制同类并发，并预留混音余量。
